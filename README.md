# Лабораторная работа №4 — PyQt5
**Выполнил:** Студент 3 курса, группа КБ-241, Кулякин Арсентий.

В данном репозитории представлены решения 6 заданий лабораторной работы, направленных на изучение графического интерфейса PyQt5, работы с базами данных SQLite и обработки пользовательских событий. Все интерфейсы спроектированы в Qt Designer.

## Описание заданий
1. **Результаты олимпиады (CSV):** Чтение данных из файла `rez.csv`, вывод в `QTableWidget` с возможностью фильтрации по номеру школы и класса. Реализована цветовая подсветка призеров (1, 2 и 3 места).
2. **База данных фильмов (SQLite):** Приложение для просмотра, добавления, изменения и удаления данных из БД `films_db.sqlite`. Реализованы проверка корректности ввода (год не из будущего, длина больше 0) и связи между таблицами (жанры).
3. **Рисовалка фигур:** Отрисовка случайных по размеру и цвету фигур по координатам курсора: круг (ЛКМ), квадрат (ПКМ), треугольник (Пробел). Использованы `QPainter` и `QPolygon`.
4. **Убегающая кнопка:** Использование Event Filter. Кнопка меняет свои координаты при попытке наведения на нее курсора (`QEvent.Enter`), оставаясь строго в пределах видимости окна.
5. **Управление НЛО:** Перемещение картинки (`QPixmap`) с помощью стрелок клавиатуры. При выходе за границу окна НЛО появляется с противоположной стороны. Проект собран в `.exe` (PyInstaller).
6. **Каталог библиотеки:** Комплексный проект. 
   - Авторизация и регистрация с криптографическим хешированием паролей (SHA-256).
   - Хранение книг и относительных путей к обложкам в SQLite.
   - Поиск по автору и названию, CRUD-операции.
   - Подгрузка дефолтного изображения `no_image.png` при отсутствии обложки.
